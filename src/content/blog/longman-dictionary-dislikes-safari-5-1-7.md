I disabled the flash player for Safari when I was upgrading to Safari 5.1.7 two weeks ago. I hate flash player due to lots of well-known reasons.

Today is my first running Longman Dictionary for Mac on my Mac since the Safari upgrade. Unfortunately Longman Dictionary didn’t run because it is a flashed application. I have to download and install a new version flash player (11.2.202.235). This version worked well with Safari, but Longman Dictionary disliked it. My favorite dictionary crashed. Luckily for me, Apple provides a detailed crash information for me. It indicates that this crash happens when it loads flash content. I suspect that my dictionary might not be compatible with new version flash player. Only one solution can fix this issue, uninstalling new installed flash player and re-installing old one.

Uninstalling old is easy. But question is which old version can work with my dictionary? I’m only sure the old one, which was installed with old version Safari, does work well with my dictionary. How can I get that version? Haha, thanks DuckDuckGo. It gives me an accurate answer. Solution is re-enable old-version flash player, which was disabled by Apple when upgraded to Safari 5.1.7. Apple didn’t deleted old flash player, and just moved it to another folder. BTW, what Microsoft will deal with this kind of upgrading? Just delete it, I vote. Detailed procedure can be found from [How to re-enable older Flash in Safari 5.1.7](http://reviews.cnet.com/8301-13727_7-57432867-263/how-to-re-enable-older-flash-in-safari-5.1.7/).

Following this HOWTO, I re-enabled old-version flash player. My dictionary comes back.

Thanks Topher Kessler, who write this great blog post.
